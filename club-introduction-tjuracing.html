工程创新中心一楼

把课堂知识变成赛道极限，把工程理想写进汽车产业未来

同济翼驰车队成立于 2007 年，隶属于同济大学汽车与能源学院，是国内大学生方程式赛场上的代表性学生车队之一。

车队围绕整车开发、控制策略、空气动力学、轻量化制造与商业传播等方向协同推进，强调真实项目中的跨部门配合与工程交付。

官网与招新推文都强调，加入车队不仅是参与竞赛，更是在高强度项目中积累工程方法、团队协作和行业沟通能力。

基本要求及投入

车队更适合愿意长期参与项目、接受训练节奏并能稳定投入时间的同学。

技术方向会接触编程、调试、数据分析与工程验证，非技术方向也需要稳定执行运营、宣传和项目协同任务。

如果你希望在真实任务里持续成长，而不是只做短期体验活动，这里会更匹配。

加入后你能获得

参与赛车相关的整车项目、部门协作和赛季任务推进，建立完整项目视角。

接触控制、建模、测试、运营、品牌传播等不同岗位，形成可迁移的项目经验。

在高投入团队中积累工程表达、协作配合和结果导向的做事方式。

部门/岗位

车队主要由动力总成、电控、底盘、车身与空气动力学、商业管理五个方向协作推进。

动力总成

发动机 / 动力系统 / 传动

负责赛车动力核心

参与动力系统方案、集成匹配与赛季阶段调校验证。

电控

控制 / 编程 / 数据

负责整车控制逻辑

围绕控制策略、程序调试、接口联调和数据分析开展任务。

底盘

悬架 / 转向 / 制动

负责车辆动态表现

关注结构设计、动态调校和整车操控稳定性优化。

车身与空气动力学

轻量化 / 复材 / 外形

负责外形与气动效率

参与车身方案、轻量化设计与空气动力学相关任务。

商业管理

运营 / 宣传 / 协调

负责项目运营与品牌表达

推进对外沟通、品牌传播、物料整理与团队运营协同。
